# Contributing

Pull requests are only accepted from the maintainers at Victron Energy. Opening a pull
request is restricted to collaborators of this repository.

Found a bug or want a feature? [Open an issue](../../issues/new/choose) that describes the
problem, how to reproduce it, and what you expected. We'll write and review the fix
ourselves.

Questions about the schedule itself (when to charge, discharge, buy or sell) belong on the
[Victron Community](https://community.victronenergy.com/): it is calculated in VRM, not in
this repository.
